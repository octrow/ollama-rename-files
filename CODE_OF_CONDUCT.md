# Code of conduct

**English** | [Русский](CODE_OF_CONDUCT.ru.md)

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good intent, no harassment. Report unacceptable behavior privately to the maintainer through a [GitHub security advisory](https://github.com/octrow/ollama-rename-files/security/advisories/new) or a direct message to [@octrow](https://github.com/octrow). Reports are kept confidential.
