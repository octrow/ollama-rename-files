# Политика безопасности

[English](SECURITY.md) | **Русский**

## Как сообщить об уязвимости

Пишите приватно через [GitHub security advisories](https://github.com/octrow/ollama-rename-files/security/advisories/new), а не в публичный issue. Ответ придёт в течение недели.

Поддерживается последняя версия.

## С чем работает приложение

- Читает файлы в выбранной папке и переименовывает их там же. Сначала копирует оригиналы в `backup_<timestamp>/`. Переименование никогда не перезаписывает существующий файл.
- Содержимое файлов уходит только в ваш локальный Ollama (по умолчанию `http://127.0.0.1:11434`, или `OLLAMA_HOST`).
- GUI слушает только `127.0.0.1` и принимает голые имена файлов внутри выбранной папки, без путей.

## Проверка скачанного файла

Файлы релиза собирает GitHub Actions, к каждому приложено подтверждение сборки (build provenance):

```bash
gh attestation verify ollama_rename_files-<version>-py3-none-any.whl -R octrow/ollama-rename-files
```
